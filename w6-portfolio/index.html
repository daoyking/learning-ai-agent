Engineering Practices

让 Agent 从「玩具」变「产品」的两件事

多数练手项目止步于「能跑」，而工程化交付需要质量护栏。W5 把评测与可观测做成可复用工具箱，并嫁接到前三个作品上。

⚖️

评测 Eval（LLM-as-judge）

改了 prompt / 工具后，怎么知道 Agent 没变差？用 rubric + LLM 评审员对输出自动打 0–10 分。

  • 确定性指标：精确匹配 / 正则 / 工具结果断言
  • LLM-as-judge：LLM 抽 JSON + zod 校验打分（score / passed / reasoning）
  • 数据集驱动：{id, input, criteria:[{name, weight}]}
  • 回归 / CI：把 runEval 接进流水线，评分掉档即红
🔭

可观测 Observability

线上 Agent 卡住 / 乱调工具，怎么排查？把每次运行的模型调用、工具调用、各阶段记成 span 时间线。

  • Span 模型：有开始/结束/耗时、可嵌套，一次运行 = 一棵 span 树
  • 零依赖 Tracer：span()/event()/report() 离线即可跑
  • 标准对接：AI SDK telemetry → OpenTelemetry / OTLP
  • 生产可迁：Langfuse / LangSmith / Jaeger 直接消费
