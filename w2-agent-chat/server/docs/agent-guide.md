# Agent 开发学习指南（示例文档）

这是一份放在 `server/docs/` 下的示例文档，用于演示 `readFile` 工具的真实文件读取能力。

## 核心概念

- **Agent**：能自主决定调用哪些工具来完成任务的 LLM 应用。
- **Tool Calling**：模型返回一个「要调用的函数名 + 参数」，由本地代码执行后把结果回灌给模型。
- **ReAct**：Reason（推理）+ Act（行动）的循环范式，是大多数 Agent 的基础。

## 前端转 Agent 的优势

1. 流式 UI 与打字机效果天然契合 LLM 的逐 token 输出。
2. 组件化思维能很好地封装「工具调用可视化」「中间步骤时间线」。
3. 调 Web API / 处理 JSON 几乎零切换。
