# RAG 是什么

RAG（Retrieval-Augmented Generation，检索增强生成）让 LLM 在回答前先「查资料」，
从而基于私有/最新知识作答，而不是只靠训练时记住的内容。

## 流程

1. 索引（Ingest）：把文档切分（chunk）→ 向量化（embedding）→ 存入向量库。
2. 检索（Retrieve）：把用户问题向量化，用余弦相似度找出最相关的片段。
3. 生成（Generate）：把检索到的片段作为上下文拼进提示词，让模型据此作答并注明来源。

## 为什么需要分块

文档太长会超出上下文窗口，且噪声大。合理分块能提升检索精度（chunk 太大召回泛、
太小容易断章取义，常见 200–500 字）。

## 重排（Re-rank）

检索 topK 之后，可再用一个精排模型对候选片段重新排序，进一步提升相关性。
