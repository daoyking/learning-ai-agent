# 前端工程师转 AI 应用开发

前端背景转 AI 应用层（AI Application Engineer）是一条被验证的优势赛道。

## 能力迁移

- TS/JS + 异步（async/Promise）：调 LLM API、串 Agent 流程零门槛。
- 流式 UI 与打字机效果：天然契合 LLM 的逐 token 输出。
- 组件化与状态管理：能优雅封装「工具调用可视化」「中间步骤时间线」。
- Web API / JSON / fetch：接模型、接第三方工具毫无障碍。

## 该避的坑

- 不要一上来啃微积分/线性代数，那是模型研究员路径，ROI 低易劝退。
- 先用自己会的 TS/Node 调 LLM API 拿正反馈，再补 Python 与算法。
- 求职期别碰模型微调/自训，检索（RAG）足够做出像样的作品集。

## 护城河

同样一个 Agent，你能做出带流式打字、步骤可视化、错误重试优雅的界面，
这正是大多数算法背景同学最弱、而市场最缺的一环。
